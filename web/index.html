        接入 AI 成员

        选成员类型，新开一个对话把提示词粘贴发送即可入会值守。一个对话 = 一个席位；对话面板保持打开（最小化可以）。

        Codex 首次接入需在本机执行一次（全局配置，已配过可跳过）：

        codex mcp add roundtable --url http://127.0.0.1:8787/mcp
        • 未选会议时，Agent 会自动加入最近创建且未停止的会议；已选中会议则提示词自带本会议 ID，更精确。
        • CLI 型成员（被 @ 时由系统自动调起）不需要提示词：右侧「+ 加入成员」选预设即可。
